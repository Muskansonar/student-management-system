# Student Management System in C++

## 📌 About the Project

A simple console-based Student Management System developed using C++.
It allows users to manage student records through a menu-driven program.

## ✨ Features

- Add Student
- Display All Students
- Search Student
- Update Student
- Delete Student
- Exit

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Console-based Application

## ▶️ How to Run

1. Open the `student_management.cpp` file in Dev-C++.
2. Compile the program.
3. Run the program.
4. Select an option from the menu.

## 🎯 Purpose

This project was created to practice C++ programming, functions,
structures, menu-driven programming and problem-solving.

## 🚀 Future Improvements

- Store student records permanently using files.
- Add student grades and percentage.
- Add a graphical user interface.
